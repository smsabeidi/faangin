Hosted Edge provides the secret-key map by key name and reserves `SUPABASE_*` from custom secret writes. A singular custom `SUPABASE_SECRET_KEY` is not a viable hosted override. Documentation does not guarantee that deleting `default` retargets it to a different named key or refreshes an already-created client on a specified schedule. All four functions intentionally use `verify_jwt=false` and enforce their own Auth/signature checks; that remains appropriate. [Edge environment variables](https://supabase.com/docs/guides/functions/secrets), [modern API-key migration](https://supabase.com/docs/guides/getting-started/migrating-to-new-api-keys).
